# BinAref Game Zone

**العب:** <https://binaref.github.io/game-zone/>

إحدى وعشرون لعبةً على شبكةٍ واحدة — بلا تسجيل ولا حسابات ولا إنترنت.
تُفتح الصفحةُ مرّةً واحدة، ثمّ تعمل بعدها بلا شبكةٍ أصلاً: افتحها في
المطار أو في السيّارة، وستجدها كما تركتها.

**تطبيق أندرويد:** [app.apk](app.apk) — وفيه ما ليس في المتصفّح: جهازك
يصير هو السرفر بنقرة، فيدخل من معك على نفس الواي-فاي إلى غرفتك.
